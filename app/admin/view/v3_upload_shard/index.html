上传分片目录 V3

每个 Bucket + 日期一行。V3 上传按当日序号把文件分摊到 upload/{bucket}/{YYYYMMDD}/{分片}/md5.ext，每 1000 个文件换一个分片目录（1000 / 2000 / ...），避免单目录文件堆积造成 Linux IO 压力。

「已分配序号」是原子自增的分配计数，不是目录里的物理文件数：秒传不取号、删除不回退，允许多几个（tolerance 高），仅用于观测分片分布。当前分片目录由该序号推算。此表由上传过程自动写入，后台只读。
