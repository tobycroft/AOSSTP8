项目管理 v3

v3 项目只维护鉴权信息：一个项目（Secret）可使用 v3 下所有应用（AI、Excel、文件上传等），采用信封鉴权（请求只传 kid 与密文，Secret 永不明文传输）。AI key 的分配与对外模型名在「AI 管理 → AI 授权」维护；v3 文件上传的存储（Bucket）在「存储管理 V3」独立维护（一项目一 Bucket，含落盘 Path、允许后缀与大小上限），与「存储管理 → 存储项目」（V1/V2 的 ao_oss）无关。
