项目管理 v3

v3 项目为通用凭证：一个项目（Secret）可使用 v3 下所有应用（AI、Excel、文件上传等），采用信封鉴权（请求只传 kid 与密文，Secret 永不明文传输）。AI key 的分配与对外模型名等 AI 配置在「AI 管理 → AI 授权」维护。「绑定存储」+「上传文件夹」共同决定 v3 文件上传的落盘位置：项目需绑定一个启用中的存储项目，否则 v3/file 接口返回 403；「上传文件夹」可指定落到 upload/ 下的哪个目录（留空则用存储项目名），local 存本站、OSS 传远程。

新增项目

每个项目每 60 秒内允许的请求次数（v3 各应用独立计数）；0 或留空表示不限速。超限返回 429 并带 Retry-After。
v3/file 上传接口按此存储的 size/ext/ OSS 配置落盘；仅列出启用中的存储项目。未绑定时调用上传接口返回 403。存储项目在「存储管理 → 存储项目」维护。
文件将存到 upload/文件夹/YYYYMMDD/md5.ext（local 存本站，OSS 传远程）。留空则用「绑定存储项目」的名称作文件夹。仅允许字母、数字、下划线、连字符，多级用 / 分隔。
凭证由服务端自动签发，创建后仅展示一次；如需更换请在列表点「重置Secret」。凭证本身不可手动指定。
