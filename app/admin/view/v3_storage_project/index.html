存储项目 V3

每个 V3 项目（对应一个 secret）可关联 一个或多个 Bucket，默认 Bucket 可选。设置了默认时，请求不传 bucket 就走默认；未设置默认时，前端/SDK 必须显式指定 bucket，否则上传接口直接失败。传了 bucket 时必须是这里勾选过的 Bucket，否则拒绝。Bucket 需先在「Bucket 配置」中创建。

配置存储项目：

勾选允许该 secret 使用的 Bucket；单选「默认」表示请求未指定 bucket 时的落点。也可以选择「不设置默认」，此时每次上传都必须在请求里指定 bucket。取消勾选会自动取消其默认标记。
