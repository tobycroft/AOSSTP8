AOSSTP8 · Private Capability Platform

AOSS, Your Full-stack Capability Hub

AOSSTP8 is the successor of AOSSTP — a ready-to-use private platform that integrates Office, file upload, WeChat, SMS, live streaming, CAPTCHA and other common capabilities, so your business can have them all in minutes and switch underlying providers with ease.

What Problems It Solves

Common capabilities at your fingertips, swappable underlying providers at any time

Plugin Upgrade Risks

Eliminates the risk of re-integrating plugins after PHP version upgrades.

2

Cross-language Hub

Acts as a cross-language relay — any language can reuse platform capabilities via APIs.

3

No More Re-reading Docs

Testing & Complement

Official SDKs

PHP & Golang versions — integrate with a single command

PHP

AossSdk

The PHP version of AossSdk — quickly integrate all platform capabilities via composer.

composer require tobycroft/aoss-sdk
Golang

AossGoSdk

The Golang version of AossGoSdk — quickly integrate all platform capabilities via go get.

go get github.com/tobycroft/AossGoSdk
