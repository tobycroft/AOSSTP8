解决什么问题

让常用能力触手可及，让业务底层随时可换

1

插件升级风险

解决插件在 PHP 版本升级后可能出现的需要重接的风险。

2

跨语言中转站

作为跨语言的中转站，任何语言都能通过接口复用平台能力。

3

告别重复查文档

降低很不经常使用的功能重复看文档导致心态爆炸的风险。

4

短时间常用能力

短时间内拥有常用能力，接入即用，无需重复造轮子。

5

灵活切换底层

更方便地切换业务底层，阿里云与腾讯云随时互换。

6

测试与互补

作为新功能的测试平台，使用 composer 和 gopkg 互补。

官方 SDK

PHP 与 Golang 双版本，接入只需一行命令

PHP

AossSdk

AossSdk PHP 版本，通过 composer 快速接入平台全部能力。

composer require tobycroft/aoss-sdk
Golang

AossGoSdk

AossGoSdk Golang 版本，通过 go get 快速接入平台全部能力。

go get github.com/tobycroft/AossGoSdk
